Background music

Upload an MP3 / M4A / WAV or grab the audio of a link, then add it to all clips here, or tick "Background music" on a clip.

Getting it from the bucket…

100% = as loud as the speech; 40% is a clearly audible background. Tick Mute original audio to drop the clip's own sound and play only the music (turn the volume up for those). The music loops if it is shorter than the clip and fades out at the end. Only the audio is redone, so this takes a second or two per clip. Only use music you're allowed to use.

Colour adjustment — all clips

Applies the same gentle grade to every ready clip; each one re-renders (slower than music, since the video is re-encoded) and keeps its background music. Small values look most natural. You can still set a different grade per clip on its card.

My brief

The writer on your Mac splits it into what the videos are about, how a script is told and how the pictures look. You can change each part after.

Not sure what to write? See an example

A brief is about the whole kind of video you make, not one story. Give it these four things:

  • What the videos are about: your niche and topics.
  • How the story is told: the hook, the build-up, the ending, what to avoid.
  • The narration: the voice, the tone, short or long sentences.
  • How the pictures look: drawing style, colours, characters, symbols.

Set up your bucket

          

            Add these lines to the .env file in the ClipForge folder (fill in your values),
            then run docker compose up -d api and reload this page.
          

          
BUCKET_NAME=my-bucket
# Your bucket's region ("auto" for Cloudflare R2)
BUCKET_REGION=ap-south-1
BUCKET_ACCESS_KEY_ID=your-access-key
BUCKET_SECRET_ACCESS_KEY=your-secret-key
# Leave empty for AWS S3. Cloudflare R2: https://<account-id>.r2.cloudflarestorage.com
BUCKET_ENDPOINT_URL=
# Optional: the folder everything goes under
BUCKET_PREFIX=clipforge

          
Keep each # note on its own line: after a value it becomes part of the value.
            Works with AWS S3 and S3-compatible storage (Cloudflare R2, DigitalOcean Spaces, Backblaze B2, Google Cloud Storage). The keys need permission to read, write and list the bucket (and delete, for Delete).
